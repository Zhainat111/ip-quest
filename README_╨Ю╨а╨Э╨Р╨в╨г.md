# IP QUEST — GitHub Pages + Firebase (орнату нұсқаулығы)

## Файлдар
- `index.html` — оқушыларға арналған ойын (40 тапсырма, 6 деңгей, үш тіл).
- `teacher.html` — мұғалімнің онлайн панелі, CSV және QR.
- `firebase-config.js` — өз Firebase Web App конфигурацияңызды осы файлға қойыңыз.
- `student-cloud.js`, `teacher.js` — онлайн синхрондау модульдері.
- `firestore.rules` — Firestore Security Rules (міндетті түрде Firebase консолінде жариялау).

## 1. Firebase жоба ашу
1. https://console.firebase.google.com → **Add project** → мысалы `ip-quest-class`.
2. **Project settings → Your apps → Web app (</>)** → тіркеңіз. `firebaseConfig` мәндерін алыңыз.
3. `firebase-config.js` ішіндегі `REPLACE_...` жолдарын өз `apiKey`, `authDomain`, `projectId`, `appId` мәндерімен ауыстырыңыз. Бұл клиентке арналған ашық идентификаторлар; ешқашан private key, service account немесе мұғалім құпиясөзін файлға жазбаңыз.
4. **Build → Authentication → Sign-in method**: **Anonymous** және **Email/Password** провайдерлерін қосыңыз.
5. **Authentication → Users → Add user**: тек мұғалім үшін email және күшті құпиясөзбен тіркеу жасаңыз. Құрылған пайдаланушының **UID** мәнін көшіріңіз.
6. **Build → Firestore Database → Create database**: қауіпсіз режимді (production) таңдаңыз, орнын таңдаңыз.
7. `firestore.rules` ішіндегі `REPLACE_TEACHER_UID` мәтінін мұғалім UID-іне ауыстырыңыз. **Firestore Database → Rules** бөліміне толық ережені көшіріп, **Publish** басыңыз. Бұл міндетті қадам: ережесіз мұғалім тізімді қарай алмайды, ал ашық ереже қауіпсіз емес.

## 2. GitHub Pages
1. https://github.com → жаңа **Public** репозиторий: `ip-quest`.
2. Осы папкадағы файлдардың бәрін репозиторийдің **түбіріне** жүктеңіз (ZIP файлын ғана жүктемеңіз). `index.html` атауын өзгертпеңіз.
3. **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
4. Бірнеше минуттан соң сілтеме: `https://GITHUB_USERNAME.github.io/ip-quest/`.
5. Оқушылар: осы мекенжай; мұғалім: `https://GITHUB_USERNAME.github.io/ip-quest/teacher.html`.
6. Сайт ашылған соң `teacher.html` арқылы кіріңіз; QR-кодты экранға шығарыңыз.

## 3. Тексеру
1. Оқушы сілтемесін **HTTPS** арқылы ашып, аты-жөнін жазып **Сақтау** басыңыз.
2. «☁️ ... Firebase-ке сақталды» мәртебесін күтіңіз, бір деңгейді аяқтаңыз.
3. Мұғалім басқа браузерде `teacher.html` ашып, email-құпиясөзбен кіріп көріңіз. Нәтиже кестеде пайда болуы тиіс.
4. Қате `permission-denied` шықса: мұғалім UID, Firestore rules жариялануы, Anonymous Auth іске қосылуы, жоба конфигурациясы бір жобаға тиесілі екенін тексеріңіз.
5. QR жасалмаса, сайт сілтемесін кез келген QR генераторға қойыңыз (QR сервисі интернетті қажет етеді).

## Маңызды шектеулер
- Бастапқы ойынның **40 тапсырмасы** сақталған; алтыншы деңгей 15 есептің 10-ын әр ойнағанда кездейсоқ береді.
- Ұпай **клиентте есептеледі**, сондықтан оны DevTools көмегімен өзгерту теориялық түрде мүмкін. Ресми емтиханға немесе жоғары тәуекелді бағалауға қолданбаңыз.
- Бір браузердегі **жеке анонимді Firebase идентификаторы** сақталады: браузер деректері өшірілсе немесе басқа телефоннан кірсе, жүйе жаңа оқушы ретінде қабылдауы мүмкін. Тек аты бірдей болуы автоматты біріктіру емес.
- Аты-жөндер Firestore-да сақталады. Оқушылар туралы деректерді жинамас бұрын мектептің дербес деректер саясаты мен ата-аналық келісім талаптарын сақтаңыз; мүмкін болса, аты-жөннің орнына бүркеншік ат/код қолданыңыз.
- Мұғалімнің кестесін **тек Firestore rules** мұғалімнің UID-іне рұқсат беріп қорғайды. `teacher.html` бетінің HTML-коды жалпыға ашық болуы мүмкін, бірақ оқушылар нәтижелерін оқи алмайды.
- Firebase қызметтері интернетті талап етеді және пайдалануға байланысты квоталар/төлемдер болуы мүмкін. Сыртқы QR қызметіне тек **қоғамдық сайт URL** жіберіледі.
- Анонимді қолданушының ұпайы жіберіледі, бірақ сервер жауаптардың дұрыстығын қайта есептемейді.
